# Weather Website

This is a weather web application built using Node.js and Express.

It fetches weather data based on user input and displays it on the web page.

---

## Tech Stack

- Node.js
- Express.js
- EJS (templating engine)
- Firebase Admin SDK
- HTML, CSS, JavaScript
- dotenv

---

## Features

- Search weather by city
- Displays real-time weather information
- Backend server using Express
- Firebase integration for backend services

---

## How to Run

1. Clone the repository
git clone https://github.com/Somyasri1/weather-website_1.git

2. Install dependencies
npm install

3. Add Firebase service file (not included for security)
firebase-service.json

4. Start the server
node index.js

---

## Note

Sensitive files like .env and firebase-service.json are not included in this repository for security reasons.
